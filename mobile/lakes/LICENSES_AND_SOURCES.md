## Safe architecture

- `/mobile/`: existing model/film functional root unchanged except a single link to this test page and one CSS class.
- `/mobile/lakes/`: separate interim placeholder page using full-width cinematic footage. No claims of real VELLARIO production.
- `/assets/lake-placeholders/`: compressed H264 1080p mobile derivatives and derived JPEG posters.
- No new hosting, APIs, database, subscriptions or paid services.
- No replacement of the canonical `mobile/catalog.json` model mapping or MAS 46 opening, no alteration of the approved 13-route sitemap.
- Full 4K original loaded on demand via Wikimedia Commons; if unavailable/unsupported the player falls back to local H264 MP4 still/picture.
- Explicit rights note for BY-SA derivatives; avoid reusing the footage commercially without retaining licensing conditions.
